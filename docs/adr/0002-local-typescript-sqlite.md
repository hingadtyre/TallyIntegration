# Local TypeScript application with SQLite

Use React with TypeScript for the browser dashboard, Node.js with TypeScript for the independently running local backend, and SQLite on local disk for application state and durable work, matching the initial single-Windows-machine deployment while keeping one application language. Keep storage access behind backend interfaces and keep Tally connectivity separable so a future server deployment and migration to a remote database can preserve business policies and dashboard behavior; that migration still requires data conversion, integration testing, secure connectivity, and a controlled publishing cutover. A C#/.NET backend was considered for native Windows service hosting, but sharing TypeScript across the dashboard and backend was preferred; the Windows startup/restart mechanism still needs explicit implementation and verification.
