# Map listings as orders arrive

Sellers can start tracking a participating account from a confirmed date and map each listing and pickup location when an order arrives. An unmapped sale stays in the order history while existing mapped listings continue syncing. During a gradual rollout, a mapped listing can temporarily show too much stock if an unmapped sale draws on the same tyres.

The seller confirms which Tally stock item and Set of supplied the saved orders. Stockbridge rechecks those orders against the selected ledger and reserves the units still awaiting a bill. A verified cancellation before dispatch stays in the history and does not, by itself, require the seller to map a listing.

A first mapping keeps the original tracking date. If company sync is on, the newly mapped destination joins the next eligible sync unless the seller chooses to keep it paused. Its unbilled orders still count against the shared item at every other mapped destination.
